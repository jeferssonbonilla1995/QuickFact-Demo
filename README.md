## 🎯 ¿Qué es QuickFact?

**QuickFact** es un sistema de facturación electrónica **multi-nicho** que permite gestionar:

- 🏪 **Comercio Normal**: Facturación electrónica SRI, inventario, cuentas por cobrar/pagar
- 🍽️ **Restaurantes**: Gestión de mesas, división de cuentas, pedidos, cocina

**✅ Sistema completo funcionando con facturación electrónica SRI.**

---

## 📋 Módulos del Sistema

| Módulo | Funcionalidades |
|--------|-----------------|
| 🏢 **Administración** | Configuración de empresa / Establecimientos / Perfiles / Usuarios |
| 🔐 **Seguridad** | Permisos por módulo / Autenticación JWT / Control de acceso |
| 📦 **Bodega / Inventario** | Artículos / Tipos de IVA / Unidades / Clases / Subclases / Kardex |
| 🧾 **Facturación Electrónica** | Emisión de facturas / Formas de pago / Secuencias / Cuentas por cobrar |
| 🍽️ **Restaurante** | Gestión de mesas / Pisos / Comandas / Cocina / División de cuentas |
| 🛒 **Adquisiciones** | Compras / Proveedores / Cuentas por pagar |
| 📊 **Reportes** | Reportes de ventas / Reportes de inventario / Reportes SRI |
| 👑 **Admin Global** | Gestión de empresas (tenants) / Planes / Módulos / Usuarios globales |

---

QuickFact nació de la necesidad de tener un sistema de facturación electrónica **multi-nicho** que se adapte a diferentes tipos de negocio (comercio, restaurantes, etc.) desde una misma plataforma.

**Características clave:**
- ✅ Multi-nicho (Comercio y Restaurantes)
- ✅ Facturación electrónica SRI
- ✅ Control por planes/suscripciones
- ✅ Seguridad por roles y permisos
- ✅ Admin global para gestión multi-empresa
